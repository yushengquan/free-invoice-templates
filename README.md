# Free Invoice & Estimate Templates

> 159 free templates for 50+ trades — plumbing, HVAC, electrical, roofing, tiling, carpentry, landscaping, and more.
> Word (.docx), Excel (.xlsx), and PDF formats. Auto-calculating. No email required.

**Website:** [fieldformtemplates.com](https://fieldformtemplates.com)

## What's inside

Each trade has three formats:

| Format | What it's for |
|--------|---------------|
| `.xlsx` | Auto-calculates tax, subtotal, and totals. Best for repeat use. |
| `.docx` | Fully editable in Word. Best for branding with your logo. |
| `.pdf` | Print-ready. Best for sending to clients as-is. |

## Usage

### Download a single template

Visit [fieldformtemplates.com](https://fieldformtemplates.com) and download the template you need — no signup, no email.

### Use the files in this repo

```
templates/
├── plumber-invoice-template.xlsx
├── plumber-invoice-template.docx
├── plumber-invoice-template.pdf
├── hvac-estimate-template.xlsx
└── ...
```

Clone or download this repo, then open the file in Word/Excel.

## Why these templates exist

Most "free invoice template" sites ask for your email, then upsell paid software. These templates are genuinely free — no signup, no watermark, no trial. They're pre-filled with line items specific to each trade, so a plumber's invoice already has "labor hours × rate, trip fee, fixture cost, fittings" instead of generic "item 1, item 2, item 3".
